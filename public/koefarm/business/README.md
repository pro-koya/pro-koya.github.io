# 法人LP（/koefarm/business/）の画像素材

S1「このひと言が、4枚の書類になる。」の4枚。ChatGPT の画像生成でつくった
**モダン・フラットUI**のイラスト。丸角の白カード＋深緑(#2e8b4e)の細い線画アイコン＋
グレーの角丸プレースホルダーバー、という同じ型でアイコンだけを差し替えてある。

**文字は画像に焼き込まない**（日本語が崩れるため）。ラベル（`1｜作業日報` など）と
語トークン（`トマト` など）は LP 側の HTML で重ねている。

|---|---|---|
| `doc-report.png` | S1 1枚目＝作業日報 | クリップボード＋チェック |
| `doc-attendance.png` | S1 2枚目＝勤怠 | アナログ時計 |

いずれも 1254×1254 PNG。

## LP 側が前提にしている画像内の座標

`business.css` / `BusinessLP.tsx` はこの実測値に合わせて要素を重ねている。
**作り直したら必ず測り直すこと**（ずれるとラベルやトークンが行から外れる）。

- 地色 = `--kf-paper` #f5f1e8（後述の正規化スクリプトで厳密に合わせる）
- 白カード = 画像の 約15%〜85%（横）／11%〜89%（縦）
- グレーバー1本目 = x 21.8%〜77.8%、y 43.2%〜46.6%（中心 44.9%）

## 再生成の手順

1. Chrome の ChatGPT ログイン済みセッションを開く
2. 下のプロンプトの「アイコン」だけ差し替えて4回投入する。
   2枚目以降は先頭に「同じシリーズの N 枚目。前の絵と完全に同じスタイル・同じカードの
   大きさと位置・同じ影・同じ背景色・同じバーの太さと本数で、アイコンだけ差し替えて」
   を付ける（付けないと構図が毎回変わる）
3. 生成完了を待つ（**1024px以上の画像が出るまで待つ**。途中は512pxのプレビューが出る）
4. 保存はページ上のJSで（ライトボックスにダウンロードボタンが出ないことがある）:

```js
const imgs = Array.from(document.querySelectorAll('img')).filter(i => i.naturalWidth >= 1024);
const img = imgs[imgs.length - 1];           // 最後＝最新。naturalWidth 順で選ぶと古い絵を掴む
const blob = await (await fetch(img.src)).blob();
const a = document.createElement('a');
a.href = URL.createObjectURL(blob); a.download = 'doc-xxx.png';
document.body.appendChild(a); a.click(); a.remove();
```

5. `public/koefarm/business/` に置いたら、地色をそろえる:

```
node scripts/normalize-koefarm-docs.mjs
```

## プロンプト（この型で狙いどおりの絵が出た）

> 日本の農業向けB2B SaaSのランディングページに載せる、モダンでクリーンなフラットベクター
> イラストを1枚生成してください。丸い角の白いカード(#ffffff)が正面から1枚置かれ、ごく薄い
> やわらかい落ち影がある。背景は淡い生成り色(#f5f1e8)の無地。カードの上部中央に
> 「**〈アイコン〉**」の細い線画アイコンを深緑(#2e8b4e)で描く。その下に、情報の行を表す
> グレーの角丸バー(プレースホルダー)を規則的に数本並べる。**実際の文字・数字・記号は一切
> 描かない**。色は白・淡い生成り・墨グレー・深緑の4色のみ。フラットで余白が多く、上質で
> ミニマルなSaaSのUIカードのような作風。人物なし、写真風ではなくフラットなベクター
> イラスト。正方形。

〈アイコン〉に入れた文言:

- 作業日報 → 「クリップボードにチェックマーク」
- 勤怠 → 「円形のアナログ時計（短針と長針があり、文字盤の目盛りは描かない）」
- 労務費 → 「円グラフ（真円が3〜4つの扇形に分かれ、そのうち1つの扇形だけが深緑で塗りつぶされ、残りは深緑の細い線だけ）」
- 仕訳 → 「左右2ページに開いた帳簿を正面から見た細い線画アイコン。中央に縦の綴じ線があり、左右対称に2列に分かれている」

## 注意（踏んだ罠）

- 背景色を #f5f1e8 と指定しても、実際には 248〜251 あたりでブレる。しかも1枚ごとに違う。
  そのまま並べると LP 上で「四角い色ムラ」に見えるので `normalize-koefarm-docs.mjs` を必ず通す
- ChatGPTの画面で **Escape を押すとチャットから離脱する**（入力中のプロンプトが消える）
- 「文字を入れない」指定を外すと日本語が崩れた絵が出る。必ず入れる
- 同じチャットで4枚続けてJSダウンロードすると、**Chrome が「複数の自動ダウンロード」を
  ブロックする**（無言で失敗し ~/Downloads に落ちない）。アドレスバーのブロック表示から
  chatgpt.com に許可を出す
